# OOP Exercises (C++)

Object-oriented programming exercises — one file per topic (`klasa1.cpp` ... `klasa22.cpp`), covering:

- classes, constructors and destructors
- encapsulation and access modifiers
- inheritance and polymorphism
- operator overloading
- composition and aggregation

## Compiling

Each file is a standalone exercise:

```bash
g++ -o zadaca klasa18.cpp
./zadaca
```
